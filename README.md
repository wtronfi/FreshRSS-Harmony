# FreshRSS Harmony

一个基于 HarmonyOS 的 FreshRSS 原生客户端。

为自托管 FreshRSS 用户提供更流畅、更稳定的移动端 RSS 阅读体验。

## 项目简介

FreshRSS Harmony 是一个 HarmonyOS 原生 RSS 阅读应用。

通过 FreshRSS API 连接个人部署的 FreshRSS 服务，
让用户可以在 HarmonyOS 设备上更加方便地管理和阅读自己的信息源。

项目定位：

- 面向个人自托管用户
- 注重本地体验与数据控制
- 提供简洁、高效的 RSS 阅读体验


适用于：

- 家庭 NAS 部署 FreshRSS
- 私有服务器 FreshRSS

---

## 主要功能

目前支持：

- FreshRSS 服务连接
- Feed 订阅浏览
- 文件夹管理
- 文章列表阅读
- 正文阅读
- 收藏文章
- 已读状态同步
- 打开原文
- 离线操作同步


---

## 项目特色


### HarmonyOS 原生体验

基于 HarmonyOS 原生技术开发：

- 符合鸿蒙系统交互习惯
- 更好的设备适配
- 更流畅的使用体验


### 本地优先

优先使用本地数据展示内容：

- 减少等待
- 提升弱网络环境体验
- 保持阅读连续性


### 离线同步

支持本地保存操作：

- 标记已读
- 收藏文章
- 离线操作队列

网络恢复后自动同步 FreshRSS。

## 使用要求

使用本应用需要：

1. 自行部署 FreshRSS 服务
2. 开启 FreshRSS API
3. 拥有 FreshRSS 用户账号

https://github.com/FreshRSS/FreshRSS
